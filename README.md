# Funds

Fund Management App.

## Requirements

- Rust single-package architecture.
- `unsafe` code is forbidden at crate level with `#![forbid(unsafe_code)]`.
- HTTP service hosted with Axum.
- OpenAPI document and Swagger UI are generated by `utoipa`.

## Run

```sh
cargo run
```

The service listens on `127.0.0.1:3000`.

## Endpoints

- `GET /health`
- `POST /funds`
- `GET /funds`
- `GET /funds/{account_id}`
- `POST /funds/{account_id}/events`
- `GET /docs`
- `GET /api-doc/openapi.json`

## Domain Model

The fund state follows Yuan's event-based model: fund equity updates, investor orders,
investor metadata updates, and taxation events are appended as events and folded into the
current fund state.
